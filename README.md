## 🌟 What is EDITH?

**EDITH** is not another generic ChatGPT wrapper. She is designed specifically to tackle college chaos — attendance calculations, exam panics, daily schedules, group projects, and college life.

She speaks like a **smart, chill, experienced Gen-Z senior** who has already survived college, knows the shortcuts, and gives practical, honest guidance without corporate fluff.

---

## 🚀 Key Features

### 1. 📊 Deterministic Attendance Manager & Bunk Calculator
- **Mathematical Integrity:** Uses pure deterministic formulas (`attended / conducted * 100`). Zero hallucinations.
- **Bunk Budget:** Automatically calculates how many future lectures you can skip while staying above your college's requirement (e.g. 75%).
- **Academic Comeback Streak:** Calculates exactly how many consecutive lectures you need to attend to escape the danger zone.
- **Interactive Simulator:** Test *"What happens if I bunk 2 lectures?"* before skipping.

### 2. 🚨 "I'M COOKED" Emergency Recovery System
- **Cooked Meter (0–100%):** Evaluates how serious your situation is based on syllabus scope, hours remaining, and preparation level.
- **Emergency Triage Plan:**
  - 🔥 **MUST DO:** High-weightage concepts and previous year questions (PYQs).
  - ⚡ **SHOULD DO:** Formula sheets and definition sweeps.
  - 🧊 **CAN SKIP:** Obscure derivations and textbook paragraphs with low ROI.
- **Sync to Schedule:** 1-click button to automatically add your recovery blocks into your calendar.

### 3. 📅 Plan My Day & Dynamic Rescheduler
- **Anti-Burnout Philosophy:** Class + Study + Gym + Food + 45-minute buffers.
- **Dynamic Rescheduling:** If you miss a study session, EDITH proposes an intelligent rebalance of your evening buffer without stressing you out.

### 4. 👥 Group Project Tracker ("What's Everyone Doing?")
- **Individual Contribution Meters:** Real-time completion percentages per team member based on assigned deliverables.
- **Constructive Senior Updates:** Summarizes project progress without insulting or shaming teammates.
- **Interactive Kanban Board:** Move tasks between *To Do*, *In Progress*, and *Completed*.

### 5. 🎙️ Voice EDITH & Neural Orb Interface
- **Futuristic Voice Orb HUD:** Sonar-ring pulses, state color transitions, animated waveforms, and telemetry strips.
- **Hands-free Operation:** Browser-native Speech-to-Text and audio speech synthesis.

### 6. 📸 EDITH Scan
- Upload college notices, circulars, or timetable screenshots.
- Automatically extracts exam dates and syllabus with a safe confirmation step before modifying your calendar.

## 🛠️ Tech Stack

- **Framework:** [Next.js 14 (App Router)](https://nextjs.org/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **UI Components:** Custom minimal futuristic design system with Lucide icons
- **Speech API:** Web Speech API (`SpeechRecognition` & `speechSynthesis`)
- **AI Brain:** Server-side Google Gemini 1.5 Flash integration with deterministic fallback engine

## ⚡ Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/iamshavu-cloud/project-edith.git
cd project-edith
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

*(On Windows, you can also simply double-click `start-edith.bat`)*
